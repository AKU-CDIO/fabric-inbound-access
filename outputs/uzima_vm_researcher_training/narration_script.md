# Uzima VM researcher training narration

## Slide 1: Uzima VM access for researchers
This short guide shows the normal path from portal login to RDP access, plus what to do when a 401 token error appears.

## Slide 2: 1. Open the portal and sign in
First, open the Uzima VM Control Portal and sign in with your approved AKU account.

## Slide 3: 2. Check VM status
After signing in, check the VM status. If it is stopped, start it and wait until it shows running.

## Slide 4: 3. Fix My RDP Access
When the VM is running, click Fix My RDP Access. The portal will repair the most common RDP blockers automatically.

## Slide 5: 4. Read the access result
Review the result panel. Green steps are complete. Amber warnings explain what still needs attention.

## Slide 6: 5. Connect with Remote Desktop
When access is updated, download the RDP file or copy the host, then connect with Microsoft Remote Desktop.

## Slide 7: 6. Keep your session active
While working, use the session controls so the auto-shutdown guard knows the VM is still in use.

## Slide 8: 7. If you see a 401 error
If Fabric or data access returns 401 unauthorized, go back to the portal and click Refresh Token, then retry your work.

## Slide 9: 8. If RDP still fails
If RDP still fails, run the fix again if your network changed. Otherwise, send the failed step to CDIO without sharing passwords or tokens.

## Slide 10: Quick checklist
The checklist is simple: sign in, check or start the VM, fix RDP access, connect, and refresh the token only when a 401 appears.
